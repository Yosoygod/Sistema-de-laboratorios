Documentación / Información

1. Descripción del Proyecto

IETC – Información de equipos tecnológicos cercanos es un sistema web informativo orientado al control y monitoreo de los dispositivos informáticos de la institución.

Muestra el inventario completo, el estado de ocupación (Libre/Ocupado), el sistema operativo y el estado de conectividad de cada equipo.

Los cambios de estado se guardan en el navegador mediante localStorage y no se pierden al recargar.

Posiblemente encuentres errores o desactualización de la información de los equipos.
2. Estructura del Sitio

Tres archivos principales:

• index.html — Estructura semántica HTML5
• style.css — Estilos y diseño responsive
• shuawder.js — Datos de equipos, persistencia y lógica de control

Secciones:
1. Menú Principal
2. Dashboard
3. Laboratorio 1, 2 y 3
4. Documentación
5. Registro de usuarios
3. Información real de cada equipo

Cada equipo registra:

• ID — Identificador único
• Ubicación — Laboratorio, biblioteca, etc.
• Especificaciones — Procesador, RAM y almacenamiento
• Estado — Libre u Ocupado
• Sistema Operativo — Windows, Ubuntu, etc.
• Conectividad — En línea / Desconectado
• Última conexión — Tiempo relativo

5. Cómo usar el sistema

1. Abre index.html en el navegador.
2. Entra a un Laboratorio.
3. Usa los botones Ocupar / Liberar.
4. Usa los botones Reconectar / Desconectar.
5. Los cambios se guardan automáticamente.
6. El Dashboard refleja los números actualizados.
